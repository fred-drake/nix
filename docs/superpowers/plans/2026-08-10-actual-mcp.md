# Actual MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide a reproducibly built, write-enabled Actual Budget MCP configuration with its password injected from SOPS.

**Architecture:** Pin the upstream TypeScript source through the repository fetcher and build it with `buildNpmPackage`. Home Manager installs that package and renders a `0400` MCP JSON file whose password is a SOPS placeholder, so no secret enters the Nix store.

**Tech Stack:** Nix flakes, Home Manager, sops-nix, `buildNpmPackage`, Actual MCP 1.12.0 source

## Global Constraints

- Pin `s-stefanov/actual-mcp` at commit `69d9413342acbecd1f6ab748300337418ec8ac6d`; do not use `npx` or an unpinned container image.
- Source `actual-password` from `config.secrets.workstation.mcp.actual` key `password`, with mode `0400`.
- Render `~/mcp/actual.json` with mode `0400`, `ACTUAL_SERVER_URL=https://actual.internal.freddrake.com`, and `--enable-write`.
- Set `ACTUAL_BUDGET_SYNC_ID=0da0a210-9782-4137-ad4a-4b6ec2edb08b`; do not add an encryption-password secret.
- Preserve the user-owned `flake.lock` modification; do not stage or commit it.

### Task 1: Pin and package Actual MCP

**Files:**
- Modify: `apps/fetcher/repos.toml`
- Modify: `apps/fetcher/repos-src.nix`
- Create: `apps/actual-mcp.nix`

**Interfaces:**
- Consumes: `repos-src.actual-mcp-src`, generated by `update-fetcher-repos` from the `actual-mcp-src` repository entry.
- Produces: a Nix package with executable `${actual-mcp}/bin/actual-mcp`.

- [ ] **Step 1: Add the source to the repository fetcher manifest**

Append this entry to `apps/fetcher/repos.toml`:

```toml
[[repos]]
name = "actual-mcp-src"
url = "https://github.com/s-stefanov/actual-mcp"
rev = "69d9413342acbecd1f6ab748300337418ec8ac6d"
```

- [ ] **Step 2: Regenerate and verify the pinned source**

Run: `just update-repos`

Expected: `apps/fetcher/repos-src.nix` contains `actual-mcp-src = pkgs.fetchFromGitHub` with the stated revision and a non-empty SRI hash.

- [ ] **Step 3: Create the package derivation**

Create `apps/actual-mcp.nix`:

```nix
{
  pkgs,
  buildNpmPackage,
  lib,
}: let
  repos-src = import ./fetcher/repos-src.nix {inherit pkgs;};
in
  buildNpmPackage {
    pname = "actual-mcp";
    version = "1.12.0";
    src = repos-src.actual-mcp-src;
    npmDepsHash = lib.fakeHash;
    meta = {
      description = "MCP server for Actual Budget";
      homepage = "https://github.com/s-stefanov/actual-mcp";
      license = lib.licenses.mit;
      mainProgram = "actual-mcp";
      platforms = lib.platforms.unix;
    };
  }
```

- [ ] **Step 4: Obtain the fixed-output dependency hash**

Temporarily retain `npmDepsHash = lib.fakeHash`, then run:

```bash
nix build --no-link --impure --expr '
  let
    flake = builtins.getFlake (toString ./.);
    pkgs = import flake.inputs.nixpkgs { system = builtins.currentSystem; };
  in pkgs.callPackage ./apps/actual-mcp.nix {}
'
```

Expected: the build fails only with the expected `got: sha256-...` hash. Replace `lib.fakeHash` with that reported hash and rerun the same command. It must succeed and print a Nix store path containing `bin/actual-mcp`.

- [ ] **Step 5: Commit the packaged source**

```bash
git add apps/fetcher/repos.toml apps/fetcher/repos-src.nix apps/actual-mcp.nix
git commit -m "feat: package Actual MCP"
```

### Task 2: Wire the SOPS password and MCP template

**Files:**
- Modify: `modules/home-manager/features/secrets.nix`
- Modify: `modules/home-manager/features/claude-code.nix`

**Interfaces:**
- Consumes: `${actual-mcp}/bin/actual-mcp` from Task 1 and `config.secrets.workstation.mcp.actual` key `password`.
- Produces: `config.sops.placeholder.actual-password` and `${home}/mcp/actual.json`.

- [ ] **Step 1: Declare the SOPS secret**

Add to the `sops.secrets` attribute set in `modules/home-manager/features/secrets.nix`:

```nix
actual-password = {
  sopsFile = config.secrets.workstation.mcp.actual;
  mode = "0400";
  key = "password";
};
```

- [ ] **Step 2: Install the packaged server**

In `modules/home-manager/features/claude-code.nix`, bind the package before `in` and include it in `home.packages`:

```nix
actual-mcp = pkgs.callPackage ../../../apps/actual-mcp.nix {};
```

```nix
actual-mcp # Actual Budget MCP server
```

- [ ] **Step 3: Render the MCP configuration**

Add this entry to `sops.templates` in `modules/home-manager/features/claude-code.nix`:

```nix
mcp-actual = {
  mode = "0400";
  path = "${home}/mcp/actual.json";
  content = builtins.toJSON {
    mcpServers = {
      actual = {
        command = "${actual-mcp}/bin/actual-mcp";
        args = ["--enable-write"];
        env = {
          ACTUAL_SERVER_URL = "https://actual.internal.freddrake.com";
          ACTUAL_BUDGET_SYNC_ID = "0da0a210-9782-4137-ad4a-4b6ec2edb08b";
          ACTUAL_PASSWORD = config.sops.placeholder.actual-password;
        };
      };
    };
  };
};
```

Run:

```bash
nix flake check
```

Expected: Alejandra changes no further formatting on a second run, and `nix flake check` succeeds without exposing the password.

- [ ] **Step 5: Commit the secret and MCP wiring**

```bash

git commit -m "feat: configure Actual MCP"
```
