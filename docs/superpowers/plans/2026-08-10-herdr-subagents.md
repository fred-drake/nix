# Herdr Subagents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install `edxeth/pi-subagents` declaratively and make its interactive children open as a dedicated pane in a new Herdr tab.

**Architecture:** Pin the Git repository in the existing fetcher-repository registry, then expose its `package.json` and TypeScript `src/` tree as a local Pi package. Register that local package in Pi’s generated settings and export the two parent-process environment variables that select Herdr and tab placement. No additional project skill, global agent definitions, or lifecycle extension is introduced.

**Tech Stack:** Nix flakes, Home Manager, Pi package metadata, Herdr, TypeScript loaded by Pi/jiti.

## Global Constraints

- Use `edxeth/pi-subagents`, not npm’s unrelated `nicobailon/pi-subagents` package.
- The package must load `./src/index.ts` through the upstream `pi.extensions` manifest entry.
- Export `PI_SUBAGENT_MUX=herdr` and `PI_SUBAGENT_HERDR_PLACEMENT=tab` from Home Manager’s Pi environment.
- Interactive children must appear as the sole pane in a newly created Herdr tab.
- Do not add a custom skill, an opinionated global agent definition, nested delegation defaults, or orchestrator-only mode.
- Stage every newly created Nix file before a Nix evaluation, because flakes only see tracked files.
- Format Nix with `alejandra`, not `nix fmt`.

### Task 1: Pin and package the correct subagent extension

**Files:**
- Modify: `apps/fetcher/repos.toml`
- Modify (generated): `apps/fetcher/repos-src.nix`
- Create: `apps/pi-subagents.nix`

**Interfaces:**
- Consumes: `repos-src.pi-subagents-src`, generated by `update-fetcher-repos` from the `pi-subagents-src` repository entry.
- Produces: a Nix package directory containing upstream `package.json` and `src/`, whose manifest registers `./src/index.ts` as Pi’s extension.

- [ ] **Step 1: Add the source registry entry**

Append this repository to `apps/fetcher/repos.toml`:

```toml
[[repos]]
name = "pi-subagents-src"
url = "https://github.com/edxeth/pi-subagents"
```

- [ ] **Step 2: Regenerate and review the immutable source pin**

Run:

```bash
just update-repos
git diff -- apps/fetcher/repos.toml apps/fetcher/repos-src.nix
```

Expected: `repos-src.nix` contains a `pi-subagents-src = pkgs.fetchFromGitHub { ... };` entry with a commit revision and SRI hash matching the new registry entry.

- [ ] **Step 3: Write the failing package-evaluation command**

Before creating the package expression, run:

```bash
nix build --no-link --impure --expr 'let
  flake = builtins.getFlake (toString ./.);
  pkgs = import flake.inputs.nixpkgs { system = builtins.currentSystem; };
in pkgs.callPackage ./apps/pi-subagents.nix {}'
```

Expected: FAIL because `apps/pi-subagents.nix` does not exist.

- [ ] **Step 4: Create the minimal local Pi package expression**

Create `apps/pi-subagents.nix` with this shape:

```nix
{lib, stdenvNoCC, pkgs}:
let
  repos-src = import ./fetcher/repos-src.nix {inherit pkgs;};
  package = builtins.fromJSON (builtins.readFile "${repos-src.pi-subagents-src}/package.json");
in
  stdenvNoCC.mkDerivation {
    pname = "pi-subagents";
    inherit (package) version;
    src = repos-src.pi-subagents-src;
    dontConfigure = true;
    dontBuild = true;
    installPhase = ''
      runHook preInstall
      mkdir -p "$out"
      cp package.json "$out/"
      cp -r src "$out/"
      runHook postInstall
    '';
    meta = {
      description = "Named interactive and background subagents for Pi";
      homepage = "https://github.com/edxeth/pi-subagents";
      license = lib.licenses.mit;
    };
  }
```

The upstream package declares only Pi-provided peer dependencies, so do not add `buildNpmPackage`, a generated lock file, or `node_modules`.

- [ ] **Step 5: Stage the new expression, format it, and verify the package**

Run:

```bash
git add apps/pi-subagents.nix apps/fetcher/repos.toml apps/fetcher/repos-src.nix
alejandra apps/pi-subagents.nix apps/fetcher/repos-src.nix
nix build --no-link --impure --expr 'let
  flake = builtins.getFlake (toString ./.);
  pkgs = import flake.inputs.nixpkgs { system = builtins.currentSystem; };
in pkgs.callPackage ./apps/pi-subagents.nix {}'
```

Expected: PASS; the resulting package root has `package.json` and `src/index.ts`.

- [ ] **Step 6: Commit the pinned package**

```bash
git add apps/pi-subagents.nix apps/fetcher/repos.toml apps/fetcher/repos-src.nix
git commit -m "feat(pi): package interactive subagents"
```

### Task 2: Register the package and Herdr tab-placement environment

**Files:**

**Interfaces:**
- Consumes: `apps/pi-subagents.nix`, a local package whose upstream `package.json` exposes `pi.extensions = [ "./src/index.ts" ]`.
- Produces: Pi’s declarative settings contain the local package, and Pi inherits `PI_SUBAGENT_MUX=herdr` plus `PI_SUBAGENT_HERDR_PLACEMENT=tab`.

- [ ] **Step 1: Write a failing configuration assertion**

Run this before editing `pi.nix`:

```bash
rg -n 'pi-subagents|PI_SUBAGENT_MUX|PI_SUBAGENT_HERDR_PLACEMENT' modules/home-manager/features/pi.nix
```

Expected: FAIL (no matches).

- [ ] **Step 2: Register the local package**

Add this item to `piPackages` in `modules/home-manager/features/pi.nix`, alongside the existing locally packaged Pi extensions:

```nix

```

- [ ] **Step 3: Export the exact parent environment**

In the same `home = { ... };` block, add:

```nix

  PI_SUBAGENT_MUX = "herdr";
  PI_SUBAGENT_HERDR_PLACEMENT = "tab";
};
```

Do not set either variable in child-agent frontmatter: placement is resolved by the parent before the child surface exists.

- [ ] **Step 4: Format and verify the declarative configuration**

Expected: the first command leaves the module formatted; the search prints the package and both variables; the Home Manager activation package builds successfully.
